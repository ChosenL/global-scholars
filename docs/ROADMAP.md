# Global Scholars OS Roadmap

This roadmap outlines the planned evolution of Global Scholars OS. Priorities may be refined based on validation results, operational needs, and user feedback.

## Current Release (RC1)

- **Stabilization:** Resolve release-blocking defects and strengthen core platform reliability.
- **Staging Validation:** Validate critical student, advisor, security, and operational workflows.
- **Production Readiness:** Complete performance, infrastructure, monitoring, and go-live checks.

## Version 1.1

- **Institution Management:** Expand tools for managing institutions, programs, intakes, and related data.
- **Admissions Workflow Automation:** Streamline application tasks, status transitions, notifications, and advisor workflows.
- **Student Experience Improvements:** Improve navigation, guidance, communication, and application visibility.
- **Reporting & Analytics:** Introduce actionable operational, admissions, and student-success reporting.

## Future Releases

- **AI-powered Application Review:** Provide secure, explainable assistance for application quality and completeness.
- **Mobile Applications:** Deliver mobile experiences for students and advisors.
- **CRM Integrations:** Connect Global Scholars OS with approved external CRM platforms.
- **Predictive Analytics:** Support responsible forecasting for readiness, engagement, and application outcomes.
